# Animation น้องผู้ตรวจ (Office Girl Pixel Art)

sprite sheet ของน้องผู้ตรวจ 5 ท่า + ตัวเล่น + หน้าดู/ตรวจคุณภาพ

## เปิดดู

ล็อกอินแล้วเข้า **`/animation`** (เช่น `http://<เครื่อง>:3800/animation`)

- เลือกท่า: พิมพ์คีย์บอร์ด / กะพริบตาและหายใจ / กินขนม / ดื่มน้ำ / ผมและตัวขยับ
- การเปลี่ยนเฟรม: **ตัดทีละเฟรม** หรือ **เฟดต่อเนื่อง** (ปรับระยะเฟดได้)
- ปรับความเร็ว (fps) และขนาด 1×–3×
- **หยุด** แล้วกด ‹ › เลื่อนทีละเฟรม หรือกดภาพในแถบเฟรมเพื่อกระโดดไปเฟรมนั้น
- กล่องผลตรวจคุณภาพของท่าที่เลือก (ผ่าน / ต้องแก้ที่ภาพต้นฉบับ)

รันในเครื่องตัวเอง: `npm run dev` แล้วเปิด `http://localhost:3000/animation`

## สร้าง sprite ใหม่

```bash
pip install pillow numpy
python3 tools/office-girl/build_sprites.py
```

สคริปต์ทำ 4 ขั้น:
1. หาขอบแต่ละเฟรมจากช่องว่างสีอ่อนระหว่างเฟรม (แถวของแต่ละท่ากำหนดใน `ACTIONS`)
2. จัดเฟรมในท่าเดียวกันให้ตรงเฟรมกลาง — หาสเกล (**เท่ากันทุกด้าน ไม่ยืดตัวละคร**) + การเลื่อน ที่ภาพทับกันได้ดีที่สุด
3. ตัดเหลือส่วนที่ทุกเฟรมมีภาพจริง แล้วตัดกลางเป็น 120 × 168
4. ส่งออก sprite sheet, เฟรมแยก และ `officeGirlSprites.ts`

เปลี่ยน reference sheet → แก้ `SHEET` และตำแหน่งแถวใน `ACTIONS` แล้วรันใหม่

## ใช้ตัวเล่นในหน้าอื่น

```tsx
import SpritePlayer from "@/app/components/SpritePlayer";
import { OFFICE_GIRL_ACTIONS, OFFICE_GIRL_FRAME } from "@/app/components/officeGirlSprites";

const a = OFFICE_GIRL_ACTIONS.typing;
<SpritePlayer
  src={a.src} frames={a.frames} fps={a.fps}
  frameWidth={OFFICE_GIRL_FRAME.width} frameHeight={OFFICE_GIRL_FRAME.height}
  mode="blend" blendMs={220} scale={2}
/>
```

| prop | ค่าเริ่มต้น | |
|---|---|---|
| `mode` | `"step"` | `"step"` ตัดทีละเฟรม · `"blend"` เฟดช่วงท้ายของแต่ละเฟรม |
| `blendMs` | 250 | ระยะเฟด (ใช้กับ `blend`) |
| `loop` | `true` | `false` = เล่นครั้งเดียวแล้วเรียก `onEnd` |
| `playing` / `frame` | `true` / 0 | หยุดแล้วโชว์เฟรมที่กำหนด |
| `scale` | 1 | ขยายกี่เท่า (จำนวนเต็มจะคมที่สุด) |
| `transitionMs` | 350 | เปลี่ยน `src` (สลับท่า) แล้วภาพเดิมจางออก |

ผู้ใช้ที่ตั้ง "ลดการเคลื่อนไหว" ในเครื่อง → ตัวเล่นไม่เล่นเอง (ยังหยุด/เลื่อนดูทีละเฟรมได้)

## ข้อจำกัดของเฟรมชุดนี้ (สำคัญ)

เฟรมใน reference sheet เป็น **ภาพหลักของแต่ละท่าที่ถูกวาดแยกกันทีละภาพ** ไม่ใช่เฟรม animation ต่อเนื่อง
สคริปต์จัดตำแหน่งให้ตรงกันได้ แต่ **สร้างเฟรมใหม่หรือวาดแก้ไม่ได้** ผลคือ

- พื้นหลังและของบนโต๊ะไม่ตรงกันทุกเฟรม → โหมด "ตัดทีละเฟรม" เห็นพื้นหลังกระพริบ
  โหมด "เฟดต่อเนื่อง" กลบได้มาก แต่ยังไม่ใช่ animation ลื่นแบบวาดทีละเฟรม
- ท่าละ 5 เฟรม (พิมพ์ 8) เปลี่ยนท่าเป็นช่วงใหญ่ ไม่ใช่ขยับเบาๆ
- ความต่างของภาพหลังจัดตำแหน่ง (0 = เหมือนกันเป๊ะ, สูงสุด 255) อยู่ที่ราว 21–49 — ดู `assets/office-girl/frames/alignment.json`

ถ้าต้องการ animation ลื่นจริง ต้องได้เฟรมที่ **วาดต่อเนื่องบนพื้นหลังเดียวกัน** (หรือตัวละครพื้นโปร่งใสแยกจากฉาก)
ขนาดเฟรมเท่ากันทุกเฟรม ตัวละครอยู่ตำแหน่ง/สเกลเดียวกัน — ใส่แทน `sheet-a.webp` แล้วรันสคริปต์ใหม่ได้เลย

## เช็กลิสต์ตรวจคุณภาพ

ตรวจด้วยตาจากเฟรมที่จัดแล้ว ขยาย 2–3 เท่า (15 ต.ค. 2569)

| ท่า | เฟรม | มือ/นิ้ว | หน้า/ผม/ชุด | ปัญหาที่พบ |
|---|---|---|---|---|
| พิมพ์คีย์บอร์ด | 8 | ✅ วางบนคีย์บอร์ดทั้งสองมือ ไม่เห็นนิ้วเกิน/ขาด/ติดกัน | ✅ คงที่ | พื้นหลังไม่ตรงกัน (เฟรม 1 ไม่มีกระถางบนตู้) · นิ้วไม่ได้ขยับทีละนิ้ว |
| กะพริบตาและหายใจ | 5 | ✅ คงที่ | ✅ คงที่ | เฟรม 3–4 มี ♣ ♪ โผล่ · หลับตา 3 เฟรมดูเป็นงีบมากกว่ากะพริบ |
| กินขนม | 5 | ✅ มือถือขนมเข้าปากเป็นธรรมชาติ | ✅ คงที่ | กล่อง/ขนมเปลี่ยนทุกเฟรม · ไม่มีจังหวะเอื้อมหยิบ · เฟรม 5 มี ♥ |
| ดื่มน้ำ | 5 | ✅ มือจับแก้วเป็นธรรมชาติ | ✅ คงที่ | แก้วเปลี่ยนขนาด/ตำแหน่ง · เฟรม 1, 5 ไม่มีแก้ว · เฟรม 5 มี ♪ |
| ผมและตัวขยับ | 5 | ✅ บิดขี้เกียจแขนครบสองข้าง | ✅ คงที่ | เปลี่ยนท่าใหญ่ ไม่ใช่ขยับเบาๆ · พื้นหลังเลื่อนมากที่สุด |

- [ ] ไม่มีแขน/มือซ้ำหรือหาย
- [ ] หน้า ทรงผม ชุด สัดส่วน เหมือนกันทุกเฟรม
- [ ] ไม่มีโลโก้แบรนด์จริงบนขนม/แก้ว/ของบนโต๊ะ
- [ ] เฟรมแรกกับเฟรมสุดท้ายต่อกันได้ (วนไม่สะดุด)
- [ ] ไม่ยืด/บีบตัวละคร (สเกลเท่ากันทุกด้านเท่านั้น)
